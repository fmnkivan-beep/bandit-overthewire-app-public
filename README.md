# BANDIT — тренажёр OverTheWire Bandit

Идея проекта принадлежит человеку, а реализацию выполнил ИИ-агент.

Учебное desktop-приложение на русском языке для OverTheWire Bandit. Оригинальная игра доступна на [официальном сайте OverTheWire](https://overthewire.org/wargames/bandit/).

Интерфейс создан на React 18, приложение — на Go. Настоящий SSH-терминал использует xterm.js; для уровней 27→32 доступен ограниченный Git-режим с проверкой разрешённых команд.

## Сборка Windows EXE

Нужны Go 1.26+, Node.js/npm, установленные зависимости frontend (`cd frontend; npm ci`), Git for Windows и Microsoft Edge или Google Chrome.

```powershell
./build.ps1
```

Готовый файл: `release/BANDIT.exe`. Он запускает локальный сервер только на `127.0.0.1` и открывает отдельное окно Edge/Chrome без адресной строки. Фронтенд и задания встроены в EXE. Git for Windows и браузер остаются системными требованиями.

При первом SSH-подключении сверяйте показанный отпечаток ключа Bandit. Введённые и неудачные SSH/Git-пароли не сохраняются; пароль Git хранится в памяти до смены этапа, режима или закрытия приложения. Подтверждённые учебные ключи сохраняются для архива уровней.

В SSH-консоли логин `banditN` подставляется по текущему заданию. После подтверждения найденного ключа приложение автоматически засчитывает задание и сохраняет прогресс. Кнопка «Следующий уровень →» появляется после зачёта и открывает следующее задание; финальное поздравительное аутро не входит в процент прохождения.

## Браузерный предпросмотр

```powershell
cd frontend
npm ci
npm run preview
```

Откройте http://127.0.0.1:4173. Предпросмотр показывает интерфейс, но намеренно не эмулирует оболочку: реальный SSH/Git доступен только через BANDIT.exe.

```powershell
npm test
npm run build
cd ..
go test ./...
```

Исходники: `frontend/src/App.tsx`, `frontend/src/TerminalPanel.jsx` и корневые Go-файлы. `build.ps1` собирает frontend, встраивает `frontend/dist` в EXE и выводит файл в `release`.

## CRT-эффект

Кнопка ЭЛТ переключает HIGH / SOFT / OFF и сохраняет выбор. HIGH включает scanlines с шагом 2px, свечение белых и оранжевых элементов, слабое искривление и RGB-сдвиг в узкой зоне у краёв, виньетку, зерно и мерцание. SOFT снижает интенсивность; OFF убирает слой и оптический фильтр. Размытие всего интерфейса отключено для читаемости. При prefers-reduced-motion движение, мерцание и обновление зерна отключаются.

## Хранение данных

В desktop-версии прогресс и подтверждённые ключи сохраняются в `%LOCALAPPDATA%/Bandit2`. Заметки, режим CRT и звук остаются в `localStorage` динамического origin и могут не восстановиться между запусками приложения. Браузерный предпросмотр хранит прогресс, ключи, заметки и настройки в `localStorage`. Введённые и неудачные пароли не сохраняются.
